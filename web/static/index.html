Adversarial RAG Security Suite · Red Team Evaluation

RAG Security & Pipeline Integrity

Experimental red-team evaluation of three major attack vectors against the live Retrieval-Augmented Generation (RAG) pipeline. Based on recent peer-reviewed security research: Behnia et al. (arXiv:2509.20324v1) and RAGuard (arXiv:2510.25025). All tests run against real SentenceTransformer embeddings (BAAI/bge-small-en-v1.5) and ChromaDB vector collections with verified test isolation.

arXiv:2509.20324v1 §IV-A 🔬 Ready

1. Document-Level Membership Inference (DL-MIA)

Determines whether target cybersecurity documents were incorporated into the RAG knowledge base.

Evaluates observable RAG retrieval behaviors by comparing known member chunks from the threat KB against external control non-member documents. Computes candidate probes, measures top-k cosine similarity and token containment, performs an optimal threshold sweep, and calculates ROC-AUC, Precision, Recall, and F1.

2. Knowledge-Base Data Poisoning

Evaluates whether injected adversarial documents with trigger phrases manipulate retrieval ranking and answers.

Evaluates pipeline vulnerability by injecting crafted malicious chunks with adversarial trigger tokens into an isolated test collection (threat_kb_sec_eval_poison). Compares clean baseline retrieval against poisoned retrieval, tests whether false mitigation overrides hijack rank-1 context, computes Attack Success Rate (ASR) and Retrieval Success Rate (RSR), benchmarks RAGuard Text Similarity (TS), and verifies safe cleanup.

arXiv:2509.20324v1 §IV-B 🔓 Ready

3. Retrieved-Content Leakage & Access Isolation

Evaluates exfiltration of sensitive canary secrets across retrieval and generation boundaries.

Injects synthetic canary secrets (CANARY-SECRET-*) into an isolated test environment (threat_kb_sec_eval_leakage). Executes direct queries and adversarial compound prompt injection queries ($q = q_s + q_c$) across tenant access boundaries. Examines both retrieved vector chunks and final generated outputs to calculate Retrieval Leakage Rate (RLR), Generation Leakage Rate (GLR), and Access Control Violations, followed by automated cleanup.
